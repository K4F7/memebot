# Separate intake progress from active state

An intake record's handling progress and its presence in the active administrative work queue are independent. Administrators close a record to archive it from active work and may reopen it later without erasing whether feedback is pending, processing, or resolved, or whether a suggestion or submission was accepted, declined, approved, or rejected. The bot does not host a reply conversation; assignees contact submitters directly using the QQ identity included in the management notification.
