# Archive content-platform deployment (historical)

Archive management does not live in this repository. The Payload Vercel/Neon/R2
operating path that previously used `apps/archive-payload` is frozen on the
immutable `archive/payload-cms` branch and is not an executable deployment path
from `main`.

Current Archive acceptance on the Koishi mainline is the fail-closed QQ read
surface documented in [`archive-qq-shortcuts.md`](archive-qq-shortcuts.md) and
[`archive-console-browser.md`](archive-console-browser.md).
